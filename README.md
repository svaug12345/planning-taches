# Planning des tâches familiales

Page de planning des corvées pour Nanon, Gaby et Tom.

**État :** deux versions coexistent

## Structure
- `version-html/index.html` : version simple, un seul fichier (s'ouvre dans le navigateur)
- `version-nextjs/` : refonte en Next.js 16 + React 19 + Tailwind 4, déployée sur Vercel

## Pour lancer la version Next.js
```
cd version-nextjs
npm install      # télécharge les bibliothèques (node_modules)
npm run dev      # puis ouvrir http://localhost:3000
```
